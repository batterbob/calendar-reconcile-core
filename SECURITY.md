# Security policy

Please report potential vulnerabilities privately through the repository's
GitHub **Security** tab using **Report a vulnerability**. Do not open a public
issue. Use a minimal synthetic reproduction; do not include real calendar
content, opaque subject identifiers, credentials, or calendar exports.

The project prioritizes identity confusion, algorithmic-complexity exhaustion,
control-character/property injection, UID/sequence correctness, and timezone
ambiguity. The `0.1.x` release-candidate line is supported during public
evaluation.
