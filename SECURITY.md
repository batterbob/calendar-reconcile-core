# Security policy

Please report potential vulnerabilities privately to the project maintainer
through the repository's security-advisory channel once one is configured. Do
not include real calendar content, opaque subject identifiers, credentials, or
calendar exports in a report.

The project prioritizes identity confusion, algorithmic-complexity exhaustion,
control-character/property injection, UID/sequence correctness, and timezone
ambiguity. Version 0.1 is local-only and unpublished; there is no release
security contact yet.
